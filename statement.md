# Project Statement

## 1. Problem Statement

Managing hospital information manually can make it difficult to organize
patient records, doctor information, appointments, and billing details.

The Hospital Management System is developed to provide a simple,
menu-driven Python application that helps manage these basic hospital
operations in an organized manner.

The system brings different hospital management activities together into
separate modules and provides validation and error handling to reduce
incorrect data entry.

---

## 2. Scope

The scope of this project includes the management of basic hospital
operations through a Python-based application.

The system covers:

- Patient record management
- Doctor record management
- Appointment management
- Billing management
- Reports and analytics
- Input validation
- Error handling

The project is designed as a modular application where different hospital
activities are handled through separate Python modules.

The current version focuses on basic hospital management and does not include
permanent database storage or advanced graphical interfaces.

---

## 3. Target Users

The system is intended for users who need to manage basic hospital
information, such as:

- Hospital staff
- Reception or front-desk staff
- Administrative staff
- Users managing patient and appointment records

The project can also be used as a basic academic demonstration of how Python
can be used to develop a modular management system.

---

## 4. High-Level Features

### Patient Management

- Add patient records
- View patient records
- Search patients
- Update patient information
- Delete patient records

### Doctor Management

- Add doctor records
- View doctor records
- Search doctors
- Update doctor information
- Delete doctor records

### Appointment Management

- Book appointments
- View appointments
- Search appointments
- Update appointments
- Cancel appointments
- Validate patient and doctor IDs

### Billing Management

- Generate bills
- View bills
- Search bills
- Update bills
- Delete bills
- Calculate total bill amount

### Reports & Analytics

- Hospital summary
- Patient reports
- Doctor reports
- Appointment reports
- Billing reports
- Total revenue calculation

### Validation & Error Handling

- Validate user input
- Handle incorrect data types
- Check duplicate IDs
- Check required records before creating appointments
- Display appropriate error messages
